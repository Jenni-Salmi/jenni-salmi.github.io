# Jenni Salmi Website 🖊

## Adding a new entry

In the file `published-translations.html` you can enter new entries in to the grid at line 68 after the common.

A new entry looks like:

```
 <div>
    <h2 class="booktitle"> BOOK NAME HERE </h2>
    <img
        class="image"
        height="500"
        src="./images/IMAGE NAME HERE"
        alt="BOOK TITLE AND AUTHOR HERE"
    />
    <h3>BOOK GENRE HERE</h3>
    <p>
     BOOK REVIEW
    </p>
    <p>
       BOOK REVIEW
    </p>
</div>
```
